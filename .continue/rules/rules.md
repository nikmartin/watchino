# Watchino

Watchino is an esp32-c6 based smartwatch app. Source is in /src.
The app is written in C++. The hardware this app runs on is the Waveshare 
ESP32-C6 2.06" AMOLED Smart Watch dev kit with touch screen, IMU, and RTC.
For reference, here are the docs for the devkit: https://docs.waveshare.com/ESP32-C6-Touch-AMOLED-2.06/Resources-And-Documents
